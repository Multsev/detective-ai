## [0.1.0] - 2026-09-14

### Added

- Первая подготовленная к публичному GitHub-репозиторию версия локальной AI-доски.
- Граф дел, карточки и связи, история исследований, вопросы, материалы и Google Контакты.
- Интеграция с Codex CLI, Web Search и проектными MCP-серверами.
- Проверка секретов в текущем дереве и Git-истории.
- GitHub Actions CI и Dependabot.
- Защита локального API от внешних Host и Origin.
- Аудит фактического покрытия Web Search и включённых MCP-источников.

### Security

- Desktop OAuth Google использует PKCE; необязательный compatibility secret читается только из локального `.env`.
- Дела, MCP-настройки, материалы и файловые OAuth-токены создаются с закрытыми правами доступа.
